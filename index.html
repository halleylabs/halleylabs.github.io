Why Halley

Named for a prediction that came true.

In 1705 Edmond Halley used Newton’s laws to predict that a comet would return in 1758. He died sixteen years before it did. It came back on schedule: the first time anyone had predicted a comet’s return.

That is how we want to work: think it through from first principles, ship it, and let the work prove itself.

Projects

Open source, shipping now.

Pieces of the agent stack we are building, released as we go.

  • TringPythonDefine a voice agent once in YAML, then run it as a cascade, speech-to-speech, or hybrid pipeline.
  • WitnessRustA recording cache for model APIs. Repeat calls cost nothing, crashed runs resume, and every call leaves a verifiable record.
  • AgentReplayJavaScriptA trace protocol and replay harness that turns every failed agent run into a replayable test.
  • PactGoA cryptographic protocol for agents to prove who they are, who sent them, and what they are allowed to do.
  • GuardianJavaScriptA judgment sidecar that reviews every agent action before it runs, at a fraction of the agent’s cost.
  • fasthandsTypeScriptModel-agnostic computer use with 91% fewer tokens than a screenshot loop. Works with a 4B model on a laptop.
  • context-brokerClaude CodeAnswers big-file reads with an exact structural outline: 80 to 95% fewer tokens in about a millisecond, all on your machine.
  • Everything elseNew work lands on GitHub first. Watch the org to see it as it ships.
